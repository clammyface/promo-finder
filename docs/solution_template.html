1The idea

The problem

Every new show needs promos, and picking them means an editor watching all of it: about 100 minutes a show, every week. Yet the rules are checkable. A clip is 20–60 s or it isn't; the hook lands in 3 s or it doesn't.

What I built

In: a zip of episode scripts. Out: ranked promos, each with the episode and start/end of every segment in order, the hook, the cliffhanger and one line on why it works. Plus an app where the editor approves or rejects.

Why Problem 1

It comes back with every show, and quality is measurable, so the hard rules can live in plain code and AI only has to supply taste. Problem 2 carries real legal risk; Problem 3 needs viewer research I couldn't do well in two days.

What I assumed Script time = edit time; cuts snap to shot changes Viewer = genre fan, not a random scroller Hook in 0–3 s; cliffhanger = cut ≤4 s after an open question Early episodes count more: tappers start at ep 1 Spoilers OK: the title says "He was a Duke"

The AI never types a timestamp

It points at line IDs; code works out the times and lengths. So there are no invented timestamps, and no "45 s" clip that is really 70.

Rules in code, taste in the model

A broken pick goes back to the model once with the exact error. If that fails, code re-cuts it like an editor would. That's how ep 41's explosion, cut at 15 s, became promo #2.

A different model judges, blind

The scout can't grade itself: it rated almost every pick 8–10. So gpt-oss-120b watches each clip from 00:00 as a genre fan who has never seen the show.

Swap the model with one flag

Any OpenAI-compatible API (--provider, --model, --base-url). It falls back when a free quota runs out, and caches every call, so a re-run takes seconds.

Text onlyIt can't see whether a slap lands. The judge reads a transcript too, and may share the rules' taste for loud lines.

6AI tools I used, and where they got it wrong

What I used

  • Claude Code as a pair programmer: code, prompts, this layout
  • Qwen 3.8 27B and gpt-oss-20b (Groq) to scout episodes
  • gpt-oss-120b (Groq) as the blind judge
  • Gemini 3.5 Flash, tried early; free tier stops at ~20 requests a day

Where it went wrong: the judge was the wrong viewer

The first judge prompt, which Claude drafted and I accepted, said "a 24-year-old scrolling TikTok, judge harshly". It scored all $v1_n test clips $v1_range out of 10, and gave the altar betrayal, the strongest hook in the show, $v1_altar/10 for being "too melodramatic". Melodrama is the product; I'd picked the wrong viewer. Rewritten as a genre fan with score anchors, the same episodes scored $v2_range and the altar scene $v2_altar.
